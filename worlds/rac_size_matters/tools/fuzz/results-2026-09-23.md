## Issue found and fixed

The first common-options determinism batch reported 74 failures in 100 attempts.
Every difference was the order of the item-link `item_pool` option; item placements
matched. `Options.ItemLinks.verify` converted a set to a list, producing different
orders across Python processes. Sorting that conversion fixes the unstable option
representation. All 100 fresh determinism attempts passed after the fix.

Three item-link unit tests and the three single-weapon regression tests passed,
including 231 single-weapon generation configurations.
